## Inside Hydro GeoAnalyst

Hydro GeoAnalyst is a local Windows hydrogeology app with a named hga desk, a short station list, and a clear last handoff. It does not try to replace the rest of the PC. It sits beside wells you already keep and holds only the station that is open now.
The layout stays small on purpose: one desk, one list, one path back. Extra samples wait for their own title. Hydro GeoAnalyst starts with a local profile and does not need a complex account system.

The hga desk stays on a project you already own. Untitled samples stay off the live list.

## Quick Start with Hydro GeoAnalyst

1. Open the last Hydro GeoAnalyst session on wells you keep, not a new empty sample list.
2. Read the hga desk and the last handoff.
3. Finish one visible sample view inside Hydro GeoAnalyst.
4. Write what changed, then close with a shorter station list than you found.
5. If the desk feels crowded, drop anything that belongs to a different project.
6. Leave the hga desk on wells you already own.
7. If a sample is not yours, leave it off the live list.
8. Keep the hga desk on wells you already keep.
9. If a station is not yours, leave it off the live list.
